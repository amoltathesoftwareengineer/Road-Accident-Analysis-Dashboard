# 🚦 Road Accident Analysis Dashboard

## 📌 Project Overview

The **Road Accident Analysis Dashboard** is a data analytics project designed to analyze road accident patterns, casualty severity, vehicle involvement, road conditions, and accident trends.

The project uses SQL for data analysis, Microsoft Excel for data preparation, and Power BI for interactive data visualization. It aims to identify important patterns in road accident data and present meaningful insights through an interactive dashboard.

## 🎯 Project Objectives

- Analyze total road accidents and casualties.
- Examine fatal, serious, and slight casualty categories.
- Identify accident trends by month, year, and time of day.
- Analyze casualties by vehicle type and road type.
- Explore road surface and light conditions.
- Compare accident patterns across urban and rural areas.
- Present findings through interactive Power BI visualizations.

## 🛠️ Tools & Technologies

- **SQL** – Data querying, filtering, aggregation, and analysis.
- **Microsoft Excel** – Data cleaning and preprocessing.
- **Power BI** – Interactive dashboard and data visualization.
- **DAX** – Measures, KPIs, and time-based calculations.
- **Power Query** – Data transformation and preparation.
- **GitHub** – Project documentation and version control.

## 📊 Dashboard Features

- Total accidents and casualties KPI cards.
- Casualties by accident severity.
- Monthly and yearly accident trends.
- Analysis by vehicle type and road type.
- Road surface and lighting condition analysis.
- Urban versus rural accident comparison.
- Interactive filters and slicers.

The data preparation process may include:

## 🔍 SQL Analysis

SQL queries can be used to:

- Calculate total accidents and casualties.
- Group accidents by severity and vehicle type.
- Compare monthly and yearly trends.
- Analyze road and environmental conditions.
- Identify categories and locations with higher casualty counts.

## 📈 Key Insights

The dashboard can help explore:

- Which vehicle categories account for the most casualties.
- How casualty severity varies across accident categories.
- Which road types have higher casualty counts.
- How accident patterns change over time.
- How road surface, lighting, and location relate to reported accidents.

Actual findings will be documented after analyzing the selected dataset.
